# The-Sage-Fashion
A fully responsive, interactive fashion landing page with shopping cart, brand slider, order form, founder profile and fully interactive and responsive



🛠️ Tech Stack

HTML5	Semantic structure, forms, accessibility.

CSS3	Custom styling, Flexbox, Grid, animations, media queries.

JavaScript (ES6)	DOM manipulation, cart logic, event handling, form validation.

Font Awesome 6	Icons for cart, social media, UI elements.
Google Fonts "Inter" font for modern typography.

No external dependencies or build step; pure HTML/CSS/JS.
